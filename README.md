# Leet Astra · LeetCode 题目 AI 助手

Leet Astra 是一个运行在 Tampermonkey（油猴）中的用户脚本。它在 LeetCode 题目页右下角加入 AI 对话面板，读取当前题目和编辑器代码，帮助你获得提示、理解代码和排查错误。

**安装即可使用，无需部署后端。** AI 对话需要配置自己的模型服务 API Key，逐行调试可直接使用。当前版本为 **3.2.0**，内置智谱 GLM 和 OpenRouter 免费模型入口，可选对接本机 LeetNote 保存笔记。

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 分步提示 | 引导你逐步分析问题；默认不直接给完整答案，除非你明确要求 |
| 讲代码+复杂度 | 结合当前编辑器代码解释实现，并分析时间、空间复杂度 |
| Debug 报错 | 结合代码以及你提供的报错、失败用例分析原因 |
| Python 3 逐行调试 | 在浏览器执行当前代码，读取题目及页面可见用例，点击代码行查看变量、循环次数、返回值和异常 |
| 代码批注 | 读取最新代码，生成带知识点注释、提示和错误标记的版本，可复制使用 |
| Python 知识点 | 直接询问语法、内置函数、标准库与语言特性，获得概念解释、最小示例、预期输出和易错点 |
| 自动附带题目上下文 | 尝试读取标题、难度、标签、题目描述、链接和编辑器代码 |
| 分开读取题目与代码 | “读取题目”只读题目信息，“读取当前代码”只读编辑器内容，各自显示读取状态 |
| 对话自动保存 | 按站点和题目保存消息与输入草稿，刷新或重新打开后恢复 |
| 流式回答 | 脚本管理器支持增量响应时逐步显示，否则等待完整响应 |
| 回答展示 | 支持基础 Markdown、代码块复制，以及服务返回的推理内容折叠展示 |
| 供应商切换 | 智谱与 OpenRouter 分别保存 Key，切换时调整接口地址和模型选项 |
| LeetNote 导出 | 将题目信息、读取到的代码和可选的最近一次 AI 回答提交到 LeetNote |

脚本匹配 `leetcode.com`、`leetcode.cn` 及其 `www` 域名下的 `/problems/*` 页面。页面结构变化可能影响读取结果。

## 安装与首次配置

### 1. 安装脚本管理器

在浏览器中安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。实际调用模型依赖它提供的 `GM_xmlhttpRequest` 等接口。

### 2. 安装 Leet Astra

打开 [脚本源文件](https://github.com/mzzzmnq/openleet/blob/main/openleet.user.js)，或尝试打开 [原始脚本安装链接](https://raw.githubusercontent.com/mzzzmnq/openleet/main/openleet.user.js)。

- 如果 Tampermonkey 弹出安装页面，确认安装。
- 如果浏览器只显示源码，在 Tampermonkey 管理面板中选择“添加新脚本”，删除默认内容，粘贴 `openleet.user.js` 的完整内容并保存。

### 3. 配置供应商和 API Key

1. 打开任意 LeetCode 题目页面。
2. 点击右下角 **⌘ Leet Astra**。
3. 点击面板右上角 **⚙**。
4. 选择供应商，填写该供应商的 **API Key**。
5. 检查模型选项，点击输入框外部使设置生效，然后发送一条消息验证。

默认配置为智谱接口和 `glm-4.7-flash`。模型能否使用、额度及价格由供应商决定；脚本中的模型名称或“免费”标签不代表实时服务承诺。

## 更新脚本

已安装的用户建议直接编辑原有脚本，以保留 Tampermonkey 为它保存的配置。

1. 打开 [最新版脚本源码](https://raw.githubusercontent.com/mzzzmnq/openleet/main/openleet.user.js)，复制全部内容。
2. 打开 Tampermonkey → **管理面板**。
3. 找到原有的 **openleet · 题目 AI 助手**（更新后为 **Leet Astra**），点击名称进入编辑页面。
4. 全选旧代码，粘贴新代码，按 **Ctrl+S** 保存。
5. 刷新已经打开的 LeetCode 题目页面。
6. 如需确认版本，检查脚本头部的 `@version`，本版应为 `3.2.0`。

只替换同一脚本的源码，配置和 API Key 通常会保留。不要为了更新先删除原脚本；删除时清理脚本数据可能丢失设置。也不要同时启用多个 Leet Astra 副本。

当前源码没有显式设置 `@updateURL` 和 `@downloadURL`，自动更新行为取决于安装来源及脚本管理器设置；上述手动方式可直接使用。

## 日常使用

1. 打开题目，等待题目描述和代码编辑器加载完成。
2. 在顶部 **问答模式** 下拉框中选择模式，下面会显示对应的使用提示。
3. 点击顶部工具栏的 **读取题目** 或 **读取当前代码**，展开 **读取详情** 检查题目、代码语言、字符数和完整性提示。两个控件分别读取，不会同时更新另一项。
4. 输入问题并发送：**Enter** 发送，**Shift+Enter** 换行。
5. 修改代码后，可以再次点击 **读取当前代码** 检查；解题模式发送消息时仍会重新读取题目，并在启用发送代码时获取最新编辑器内容。

如果想问 Python 语法，选择 **Python 知识点** 后直接输入问题，无需点击“读取题目”；具体用法见下方。

所有模式默认采用适合小窗口的简短回复：提示模型将正文控制在 180 个汉字以内、最多 3 个短要点，围绕当前代码和题目相关的 1–2 个核心知识点展开。代码仅在必要时给出最小片段，不逐行复述或扩展无关内容。需要更多说明时直接说“详细解释”，需要完整解法时明确提出。长度由提示词引导，实际输出取决于模型，插件不会强行截断答案。

提问示例：

- “先给我一个提示，不要直接给完整答案。”
- “解释我现在的代码，为什么时间复杂度是 O(n²)？”
- “输入 `[3, 3]`、目标值 `6` 时结果不对，帮我定位原因。”

**Debug 模式不会自动采集运行结果、报错日志或失败用例**，请将这些内容粘贴到输入框中。

其他操作与设置：

| 操作或设置 | 作用 |
| --- | --- |
| 清空 | 删除本题已保存的聊天记录和输入草稿，不删除其他题目记录或供应商配置 |
| 读取题目 | 只读取标题、描述、难度、标签和链接，不访问编辑器 |
| 读取当前代码 | 只读取编辑器内容，不读取题目；Python 知识点模式也可使用 |
| ✕ | 隐藏助手面板 |
| 顶部 A− / A+ | 调整对话正文、代码和输入框字号，范围 12–22 px，默认 14 px，自动保存；刷新后恢复 |
| 底部 LeetNote | 展开「存入 LeetNote」「启动 LeetNote」菜单 |
| ⚙ → 完成 | 打开或关闭独立滚动的设置面板，也可按 Esc 关闭 |
| 拖动顶部标题栏 | 将整个对话框移动到页面可见区域内，自动记住位置 |
| 双击顶部标题栏 | 恢复右下角默认位置 |
| 把当前编辑器里的代码发给模型 | 控制 AI 请求是否附带自动读取的代码；不影响手动输入，也不控制 LeetNote 导出 |
| 打开面板时自动读取题目 | 打开面板时只读取题目信息；解题模式发送时重新读取题目和可选代码，Python 知识点模式不自动读取题目 |

### 给当前代码添加批注

1. 在题目编辑器中写好代码，并启用设置中的 **把当前编辑器里的代码发给模型**。
2. 选择 **代码批注**，直接点击 **发送**；也可以输入关注点，例如“重点看循环边界”。发送时会重新读取最新代码和题目。
3. 回答会展示带批注的代码，点击代码块的 **复制** 即可使用。原编辑器不会自动改写。

提示模型保留原代码、缩进和已有注释，只在关键位置新增 **【知识点】、【提示】、【错误】、【待确认】** 注释，默认批注 3–5 处或更少。明确错误说明触发条件，不确定的问题标为待确认；不会为了批注而强行寻找错误。批注模式允许输出完整代码，不受默认 8 行代码片段建议限制，额外说明仍保持简短。

代码为空、只读到可见片段、关闭发送代码或超过 8,000 字符时，不会发起批注请求，并说明原因。批注由模型生成，复制到编辑器前应核对原代码是否保留；不会自动执行代码或验证模型判断。

### Python 知识点模式

在面板中选择 **Python 知识点**，直接询问不理解的语法，或粘贴一段短代码。例如：

- “`nums[::-1]` 是什么意思？和 `nums.reverse()` 有什么区别？”
- “`enumerate(nums)` 怎么用？为什么可以写成 `for i, num in enumerate(nums)`？”
- “列表推导式里的 `if` 应该放在哪里？”
- “`is` 和 `==` 有什么区别？判断 `None` 应该用哪个？”
- “`*args` 和 `**kwargs` 分别表示什么？”

该模式默认按 **Python 3** 讲解，用一句话回答核心语法，优先结合用户代码中的表达式说明；必要时才补充最多 5 行的示例和预期输出，以及一条易错点。示例不会在插件中实际执行。

知识点模式不附带当前题目，“读取题目”按钮会禁用。需要解释编辑器里的语法时，可以点击 **读取当前代码**，再问“这段语法是什么意思”；也可以直接把片段贴到输入框。

未点击“读取当前代码”时，知识点模式不会自动读取代码。点击后，在启用“把当前编辑器里的代码发给模型”的前提下，后续发送都会重新获取当前代码，避免使用修改前的旧版本。刷新、切题或清空后，需要重新点击；只切换问答模式会保留本次页面的代码读取选择。关闭发送代码的设置仍然生效，手动读取不会自动打开它。

五种模式共用当前题目的已保存对话，切换模式不会清空历史；已有聊天中手动粘贴的代码仍可能作为历史上下文发送。模式选择会随设置保存，知识点问答也按题目自动保存。

### 对话自动保存与恢复

发送问题时立即保存，回答生成过程中和输入草稿时每隔约 500 毫秒保存待写入内容；隐藏或正常关闭页面时会尝试立即写入剩余内容。面板显示保存状态，失败时会提示先复制重要内容。

- 同一浏览器、同一脚本安装下，刷新或重新打开同一道题，会恢复该题最近 **200 条消息**和未发送草稿。
- 切换题目会自动载入对应记录；题目描述、提交记录等同题子页面共用记录。`leetcode.com` 和 `leetcode.cn` 分开保存，`www` 与非 `www` 同站点共用记录。
- 发给模型的历史上下文最多包含最近 **24 条已完成消息**，页面可查看的保存记录可以更多。
- 关闭页面会中断正在生成的回答；重新打开后会显示已保存的部分内容和中断提示，不会自动续传或重新发送请求。
- 保存用户消息、回答正文、错误状态和草稿；欢迎语、读取提示及折叠的推理内容不保存。
- **清空**会同时清除本题已保存的消息与草稿；清空或切题后，旧请求的后续内容不会写入当前对话。

记录保存在 Tampermonkey 的脚本存储中，不提供跨设备同步；卸载脚本并删除数据会失去记录。多个标签页同时编辑同题记录时以最后写入为准，暂不实时合并。浏览器异常退出时，最后约 500 毫秒尚未写入的内容可能丢失。

2.4.0 之前关闭页面后已经丢失的对话无法恢复。

## Python 3 逐行调试

1. 在题目编辑器中选择 **Python 3** 并写入代码，打开 Leet Astra → **逐行调试**。
2. 点击 **读取代码与用例**。调试区导入题目描述中的输入示例，以及当前可见的测试用例编辑框。
3. LeetCode 中后续添加的测试用例，需要先切换到该用例，再点击读取。已经读取的页面用例会在本次页面会话中保留。也可以点击 **添加用例**，直接输入参数。
4. 选择用例，点击 **运行当前用例**。每次运行都会重新读取编辑器的最新代码。
5. 可选填写 **预期输出**（Python/JSON 字面量，例如 `[0, 1]`），运行后查看比较结果。留空时不比较。
6. 点击调试区的代码行查看局部变量。循环内同一行执行多次时，通过 **所选行的执行记录** 切换，也可使用 **上一步 / 下一步** 浏览整个轨迹。

**变量对应所选行执行前的状态。** 变化高亮与同一次函数调用的上一条记录比较，标记新增、删除及 `旧值 → 新值`；递归调用各自比较。首次记录展示初始状态。截断的变量快照可能隐藏深层变化。 查看赋值后的结果时，进入下一步。函数返回事件显示返回值，异常事件显示异常信息。循环体中的次数从 1 开始；首次检查循环条件时显示 0，循环头显示已经进入循环体的次数。嵌套循环分别标注各自代码行与次数。

预期输出比较使用完整返回值，检查类型、值及数组顺序，并显示首处差异路径。支持基本类型、列表、元组和字典；浮点数使用精确比较。复杂对象、执行出错或超出比较限制会明确提示未比较。多解题、无序答案、原地修改题和带容差的浮点题需要按题意人工核对。

用例支持题目里的命名参数：

```python
nums = [2, 7, 11, 15], target = 9
```

也支持每行一个位置参数、跨行数组和矩阵，以及 `null`、`true`、`false`：

```python
[2, 7, 11, 15]
9
```

自动识别单一公开 `Solution` 方法或顶层函数。代码有多个方法时，在入口输入框填写 `twoSum` 或 `Solution.twoSum`。支持按参数注解将数组转换为 `ListNode` 链表、`TreeNode` 层序二叉树。需要构造参数及多次操作的设计类题目、LeetCode 专有交互接口需要自行编写适配调用。

执行使用浏览器 Worker 中的 [Pyodide](https://pyodide.org/en/0.29.3/usage/webworker.html)。首次运行从 `cdn.jsdelivr.net` 下载 Python 环境，后续资源可由浏览器缓存。调试代码和用例在本机浏览器执行，调试功能无需模型 Key。浏览器需要允许 Worker 和 WebAssembly；加载失败时检查网络及页面安全策略。

每次运行最多记录 2,000 个事件，追踪执行限时 3 秒，执行线程另有 8 秒终止限制。变量快照对长字符串、深层结构和大容器进行截断；任意自定义对象以类型名显示。可以随时点击 **停止**。运行结果用于查看选定用例的执行过程，LeetCode 提交结果仍由站点评测决定。

在调试区新增或编辑的用例及预期输出按站点和题目自动保存，最多保存 30 个。轨迹在内存中保存，刷新后重新运行。切换题目、修改调试输入或返回对话会取消正在运行的任务。

## 供应商与模型配置

当前仅提供智谱和 OpenRouter 免费模型，接口地址由供应商自动设置。点击聊天区顶部的当前模型，或 **⚙ → 模型连接**，即可切换供应商和模型。Key 分别保存；设置中提供对应平台的 Key 创建入口。

| 供应商 | 免费模型 | 适用方向 |
| --- | --- | --- |
| 智谱 | GLM-4.7-Flash（默认） | 中文题解、代码解释 |
| OpenRouter | MiniMax M3.1 Flash `:free` | 代码分析、多步骤问题 |
| OpenRouter | Nemotron 3 Ultra `:free` | 复杂推理、排错 |
| OpenRouter | North Mini Code `:free` | 专门面向代码生成与软件工程 |

选型核验日期：**2026-10-22**。MiniMax 和 Nemotron 在 [OpenRouter 免费模型榜](https://openrouter.ai/collections/free-models) 的编程使用分类中活跃；该榜按使用量排列。North Mini Code 是其中专门面向编码的模型。模型 ID 和零输入/输出价格均通过 [官方模型目录](https://openrouter.ai/api/v1/models) 核对。智谱的 [官方公告](https://www.zhipuai.cn/zh/news/148) 确认 GLM-4.7-Flash 免费，且旧 4.5-Flash 已由它替代。

OpenRouter 需要注册账户并创建自己的 API Key，OpenCode Go 的订阅和 Key 无法通用。免费服务有请求次数、速率和容量限制，具体以 [官方额度说明](https://openrouter.ai/docs/api-reference/limits) 和账户显示为准。候选列表固定在脚本中，免费模型下架或限流时会显示请求错误，请手动切换；脚本使用明确的 `:free` ID。

升级时会清除插件中保存的 OpenCode Key，并将原 OpenCode 接口切换到智谱；已保存的智谱 Key、对话与笔记设置保留。旧付费模型选择自动改为免费候选。此操作影响插件本地配置，订阅续费设置仍需在供应商账户中管理。

请求使用 Chat Completions：智谱 `https://open.bigmodel.cn/api/paas/v4/chat/completions`，OpenRouter `https://openrouter.ai/api/v1/chat/completions`。初始化只检查 Key 是否填写，真正的认证和模型可用性由发送消息验证。对话超时为 180 秒。

## 题目与代码如何读取

题目内容通过页面 DOM 选择器识别。代码读取按以下顺序尝试：

1. **当前编辑器模型**：页面公开 Monaco 编辑器接口时，查找可见、可编辑的实例，优先选择当前有输入焦点或最近获得焦点的编辑器。
2. **唯一可识别模型**：只公开模型列表时，在候选模型明确唯一的情况下读取；不再按代码长度猜测当前模型。
3. **可见代码片段**：无法取得完整模型时，从可确定的编辑器 DOM 中读取已渲染代码行。

每次读取都会重新获取模型内容，不保存第一次读取的代码快照。编辑器被清空时，也不会回退到其他旧模型中的代码。

如果面板出现 **“未获取完整代码”**，表示当前读取不可视为完整源码。Monaco 按视口渲染内容，滚动、折行等因素都可能影响 DOM 片段。此时请手动复制完整代码到聊天输入框。

目前给模型附带的题目描述和自动读取代码各最多 **8,000 字符**。面板显示的是读取到的代码字符数，不能据此判断长代码是否已完整发送。

## 存入 LeetNote

这是可选功能，不影响 AI 对话。需要自行运行支持 `/api/v1/import/note` 的 [LeetNote](https://github.com/mzzzmnq/leetnote) 服务。

### 配置步骤

1. 启动 LeetNote，并按服务端说明生成访问令牌。原有配套命令示例为：

   ```powershell
   cd leetnote-api
   go run ./cmd/token -user <你的用户名> -name "Leet Astra 插件"
   ```

   命令在 LeetNote 项目中执行，不是在 Leet Astra 目录中执行；具体以所用服务端版本为准。

2. 在 Leet Astra 的 **⚙** 中填写 **LeetNote 地址**（默认 `http://127.0.0.1:8080`）和 **LeetNote 令牌**。
3. 按需勾选 **导入时把最近一次 AI 讲解写进笔记正文**。
4. 展开底部 **LeetNote** 菜单，点击 **存入 LeetNote**，查看面板中的成功或错误提示。

### 从助手启动本机全部服务（Windows）

面板中的 **启动 LeetNote** 会调用本机启动器，先通过 LeetNote 的 PostgreSQL 启动函数等待数据库能够接受连接（最多 120 秒），成功后再执行项目已有的 `start-all.ps1 -Quiet`。数据库未就绪时会停止后续启动并记录错误，避免数据库仍在恢复时 API 提前启动失败。它会启动 PostgreSQL、可选的 Redis、Go API、AI 服务和网页，已运行的服务会跳过。启动不会自动导入笔记；看到就绪提示后，再点击 **存入 LeetNote**。

**从旧版升级启动器时，除了更新油猴脚本，还需更新本机 Leet Astra 仓库的整个 `scripts/` 目录（例如在该目录运行 `git pull`）。** 只更新油猴脚本不会更新 Windows 本机启动逻辑。项目路径未变时无需重新注册协议。

首次需要在本机安装一次启动器。在 Leet Astra 目录运行（将路径换成你的 LeetNote 项目）：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-leetnote-launcher.ps1 -LeetNotePath "D:\Projects\leetnote"
```

启动器仅注册当前 Windows 用户的 `openleet-leetnote://start` 协议，无需管理员权限，并调用安装时指定的 LeetNote 项目；网页不能通过该协议传入命令或更换路径。请保留 Leet Astra 目录；项目移动后重新运行安装命令。卸载启动器不会停止服务：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-leetnote-launcher.ps1 -Uninstall
```

点击启动时，浏览器可能要求允许打开外部应用。助手最多等待四分钟，检查默认端口的 API / 数据库（8080）、AI（8000）和网页（5173）。Redis 为可选服务，不属于页面就绪判断。服务日志位于 `%TEMP%\leetnote-logs`，启动器日志位于 `%TEMP%\openleet-leetnote.launcher.log`，启动输出和错误分别为 `%TEMP%\openleet-leetnote.start.out.log`、`%TEMP%\openleet-leetnote.start.err.log`。未安装启动器、取消浏览器提示或服务启动失败时，会提示超时；请按提示检查对应服务和启动器日志。

此按钮适用于默认端口的本机部署。远程服务器、Docker 或自定义端口仍需使用对应部署的启动方式；AI 对话本身不需要安装启动器。

### 导出内容

- 题目 `slug`、标题、题号（能识别时）、难度和链接。
- 当前读取到的非空代码，以及识别到的语言。
- 可选的最近一次成功 AI 回答，作为 Markdown 笔记正文。

脚本将数据发送到 `<LeetNote 地址>/api/v1/import/note`，展示服务端返回的新建、更新及关联结果。重复导入如何合并笔记由 LeetNote 服务端决定。题目完整描述目前不作为独立字段导出。

**当前导出尚未阻止不完整代码片段提交。** 如果读取提示代码不完整，请先确认完整代码能够读取，再导出，避免把片段保存为解法。

## 数据存储与请求流向

```text
LeetCode 题目页面
  └─ Leet Astra 用户脚本
       ├─ GM_xmlhttpRequest → 所配置的模型接口
       └─ GM_xmlhttpRequest → 所配置的 LeetNote 服务（点击导出时）
```

- 正常 Tampermonkey 环境中，设置、供应商 Key、LeetNote 令牌和按题目保存的对话通过 `GM_getValue` / `GM_setValue` 存储。
- AI 请求包含当前题目上下文、可选代码及保留的对话历史，发送至配置的模型接口；本项目不提供中转服务器。
- LeetNote 令牌用于发往所配置 LeetNote 服务的请求。
- 缺少 GM 存储接口时，代码保留了使用 `localStorage` 的降级方式；离线演示也使用 `localStorage`，不应在演示页填写真实密钥。

`GM_xmlhttpRequest` 通过脚本管理器发起跨域请求，避免普通页面 `fetch` 受到目标服务 CORS 配置限制。源码的 `@connect *` 用于兼容手动配置接口地址，并另列了 `127.0.0.1` 和 `localhost`。

## 常见问题

| 现象 | 排查方法 |
| --- | --- |
| 看不到助手入口 | 确认 Tampermonkey 和脚本已启用，地址在支持的 `/problems/*` 下；保存脚本后刷新页面 |
| 提示没有 `GM_xmlhttpRequest` | 通过 Tampermonkey 安装，不要直接将源码粘贴到开发者控制台运行 |
| 修改代码后仍读到旧内容 | 更新至最新版并刷新页面；点击实际代码编辑器，再点“读取当前代码”，检查是否提示代码不完整 |
| 提示未获取完整代码 | 页面可能未公开 Monaco 接口，或存在多个无法区分的编辑器；将完整代码粘贴到聊天输入框 |
| 显示当前编辑器代码为空 | 当前识别的编辑器模型没有代码；确认选中的编辑器和语言是否正确 |
| 刷新后没有恢复聊天 | 确认已更新至 2.4.0、处于同一站点和题目，并且保存状态没有报错；旧版已丢失的记录无法恢复 |
| HTTP 401 或 403 | 检查当前供应商 Key 是否正确，以及账户是否有该接口或模型权限 |
| HTTP 429 | 检查供应商限流或额度情况，稍后重试或选择可用模型 |
| HTTP 404 或模型不存在 | 检查基础地址是否重复包含 `/chat/completions`，以及模型是否被当前端点支持 |
| 状态正常但发送失败 | 初始化检查 Key 是否已填写，实际对话才验证认证和模型 |
| 180 秒超时或网络错误 | 检查目标地址、网络连接和服务可用性 |
| 没有逐字显示回答 | 脚本管理器可能缓冲了响应，需等待完整返回；也可能是服务返回格式不兼容 |
| LeetNote 导出失败 | 检查服务是否启动、地址和令牌是否正确；401 表示令牌校验失败 |

反馈问题时，建议提供脚本版本、浏览器和脚本管理器版本、题目链接、操作步骤，以及面板错误提示。不要附上真实 API Key 或令牌。

## 已知限制

- 题目和编辑器识别依赖 LeetCode 页面结构及可访问接口，站点更新可能影响兼容性。
- DOM 降级读取仅覆盖已渲染片段；LeetNote 导出尚未阻止这类片段提交。
- 自动附带的题目描述和代码各截取前 8,000 字符，当前没有独立的长内容截断提示。
- 每题保存最近 200 条消息，发送给模型的历史最多 24 条；多标签页同时修改同题暂不实时合并。
- 生成时可点击 **停止回答**，取消浏览器请求并保留已收到的文字；清空、切题和关闭页面也会取消请求。服务端已完成的处理仍可能计入额度。
- 流式解析当前按 LF 空行分帧，对仅使用 CRLF 分隔的事件流仍需完善兼容。
- 模型列表采用核验时的固定候选，服务商后续调整免费额度或下线模型时需要更新脚本。
